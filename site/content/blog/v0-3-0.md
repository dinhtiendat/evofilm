`v0.3.0` tập trung vào nâng cấp kiến trúc nền tảng nhà cung cấp mô hình và tối ưu trải nghiệm quản lý mô hình.
Phiên bản này tập trung giải quyết các vấn đề "tính mở rộng năng lực nhà cung cấp, tính nhất quán phân tích mô hình mặc định, hỗ trợ URL nền tảng đa phương thức, tính khả dụng cấu hình mô hình phía frontend".

## Highlights

- Tái cấu trúc đường đăng ký và phân tích nhà cung cấp LLM, nâng khả năng mở rộng và bảo trì.
- Thêm API liên quan năng lực nhà cung cấp được hệ thống hỗ trợ, frontend và backend có thể phát hiện biên độ năng lực động.
- Mở rộng mô hình nhà cung cấp, hỗ trợ URL nền của hạng mục ảnh/video.
- Di chuyển chiến lược mô hình mặc định (từ đánh dấu mặc định tường hợp sang hội tụ về cài đặt mô hình).
- Tối ưu tương tác trang quản lý mô hình và nhà cung cấp, bổ sung tính nhất quán về style và hành vi của nút thao tác.

## Added

- **Giao diện phát hiện khả năng nhà cung cấp**
  - thêm API liên quan "năng lực nhà cung cấp hệ thống hỗ trợ" và "danh sách nhà cung cấp hỗ trợ", giảm phán đoán năng lực ứng biến cứng phía trước.
- **Hỗ trợ khả năng nhà cung cấp đa phương thức**
  - Bổ sung hỗ trợ năng lực hình ảnh, video và URL gốc trong mô hình nhà cung cấp và đường dẫn tác vụ.
- **Hỗ trợ nhà cung cấp Alibaba Bailian**
  - Kết nối nhà cung cấp mới và mở rộng danh sách năng lực, bổ sung hỗ trợ hạng mục văn bản.
- **Tăng cường khả năng lớp thích ứng tích hợp**
  - Bổ sung thực hiện và bao phủ test cho các đường dẫn thích ứng ảnh/video liên quan OpenAI, Volcengine.

## Changed

- Tái cấu trúc logic tiêm phụ thuộc LLM và xây dựng mô hình văn bản mặc định, đường phân tích rõ ràng hơn.
- Kiến trúc chuẩn bị tạo ngày càng thống nhất, tương tác liên quan trung tâm tác vụ được tối ưu theo.
- Nâng cấp tương tác và phản hồi trực quan của trang quản lý mô hình/nhà cung cấp ở frontend (kể cả cột thao tác).
- OpenAPI và generated client đã đồng bộ cập nhật theo API của phiên bản này.

## Breaking Changes

- Chiến lược mặc định của mô hình có điều chỉnh: ngữ nghĩa `is_default` bị di trú/hội tụ vào cấu hình mô hình; bên gọi phải xử lý logic mặc định theo cấu trúc mô hình mới.
- phán đoán năng lực nhà cung cấp nên chuyển sang dùng API khám phá năng lực phía sau；các thực hiện dựa trên enum tĩnh/ứng biến cứng phía trước cần chuyển đổi theo.
- Nếu chưa đồng bộ OpenAPI và generated client mới nhất, trường liên quan mô hình và nhà cung cấp có thể không khớp type.

## Deprecations

- Việc hardcode “tập hợp năng lực do nhà cung cấp hỗ trợ” ở frontend bước vào đường loại bỏ.
- Đường dẫn dùng trường đánh dấu mặc định cũ để điều khiển trực tiếp lựa chọn mặc định của mô hình bước vào đường loại bỏ.

## Fixed

- Sửa vấn đề lấy giá trị ngữ cảnh gửi và xuất còn sót trong dịch vụ tạo.
- Sửa chi tiết tương tác cột thao tác và tính nhất quán phong cách của trang quản lý mô hình/nhà cung cấp.
- Sửa vấn đề hành vi ranh giới trên đường định tuyến năng lực của một số tác vụ và dịch vụ.

## Security

Phiên bản này không chứa mục sửa lỗi bảo mật đã công bố công khai.
Nếu phát hiện vấn đề bảo mật tiềm ẩn, vui lòng phản hồi qua kênh bảo trì một cách riêng tư, tránh tiết lộ công khai chi tiết có thể bị khai thác.

## Known Issues

- một số trang lịch sử nếu vẫn dùng ngữ nghĩa trường mô hình mặc định cũ, có thể gặp hiển thị hoặc lựa chọn không nhất quán ở các kịch bản biên.
- Nếu thứ tự triển khai sai (lên code trước, di trú sau), quy trình liên quan chiến lược mặc định mô hình có thể gặp lỗi chạy.

## Migration Guide

Phiên bản này có thay đổi cơ sở dữ liệu và hợp đồng API, đề nghị nâng cấp theo thứ tự sau:

1. thực thi các migration liên quan phiên bản này trong `backend/sql` (chú trọng `005`, `006`).
2. Triển khai dịch vụ phía sau và bộ phận thực thi tác vụ.
3. Thực thi `pnpm run openapi:update` và triển khai sản phẩm generated client phía frontend.

## Rollback Notes

Nếu cần hoàn tác khẩn cấp, hãy giữ phiên bản trước/sau và cơ sở dữ liệu nhất quán:

1. Trước tiên hoàn tác frontend về phiên bản khớp với OpenAPI cũ.
2. Sau đó hoàn tác phía sau về phiên bản ổn định mục tiêu.
3. Nếu đã chạy migration không thể đảo ngược, ưu tiên dùng chiến lược đọc/ghi tương thích, không trực tiếp rút lại cấu trúc bảng.

## Compatibility Matrix

| Thành phần | Yêu cầu v0.3.0 | Mô tả |
| --- | --- | --- |
| Backend | `v0.3.0` | cần chuỗi đăng ký/phân tích nhà cung cấp mới và API khám phá năng lực |
| Frontend | Sinh lại dựa trên OpenAPI `v0.3.0` | Bắt buộc đồng bộ generated client liên quan mô hình/nhà cung cấp |
| Database | Đã thực thi migration SQL của phiên bản này | Chiến lược mô hình mặc định và trường năng lực nhà cung cấp phụ thuộc kết quả migration |
| Task Worker | triển khai cùng phiên bản với backend | đảm bảo tính nhất quán thực thi tác vụ của chuỗi năng lực ảnh/video |

pnpm exec tsc --noEmit

uv run pytest backend/tests -q

## Upgrade Checklist

- [ ] Đã thực thi và xác minh xong di trú database (gồm `005`, `006`).
- [ ] Dịch vụ backend và thành phần thực thi tác vụ đã nâng cấp lên `v0.3.0`.
- [ ] Client generated phía trước đã đồng bộ với OpenAPI mới nhất.
- [ ] Xác thực đường dẫn API phát hiện năng lực nhà cung cấp và chiến lược mặc định của mô hình.
- [ ] Chuỗi thao tác trang quản lý mô hình/nhà cung cấp đã kiểm chứng đầu-cuối đạt.
